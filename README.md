# Dotfiles

Personal configuration files for Linux desktop environment with Sway (Wayland) and development
tools.

## What's Included

### Window Manager & Desktop Environment
- **SwayFX** - Enhanced Wayland compositor with animations and effects
- **Waybar** - Customizable status bar with system monitoring and custom scripts
- **Greetd + ReGreet** - Modern display manager with GTK greeter
- **Swaylock Effects** - Lockscreen with blur and effects
- **Swayidle** - Idle management daemon
- **Wlogout** - Logout menu with power options

### Notifications & OSD
- **SwayNC** - Notification daemon with Do Not Disturb mode
- **SwayOSD** - On-screen display for volume and brightness
- **Batsignal** - Battery level notifications

### Application Launchers & Tools
- **Wofi** - Application launcher and dmenu replacement
- **Cliphist** - Clipboard manager for Wayland
- **Wdisplays** - Display configuration tool
- **Waypaper** - Wallpaper selector

### Screenshot & Media
- **Grim + Slurp** - Screenshot tools for Wayland
- **Swappy** - Screenshot annotation tool
- **Feh** - Image viewer

### Terminal & Shell
- **Alacritty** - GPU-accelerated terminal emulator
- **Fish** - Modern shell with syntax highlighting and autosuggestions
- **Tmux** - Terminal multiplexer
- **Tide** - Fish prompt theme
- **Fisher** - Fish plugin manager

### Editors & Development
- **Neovim** - Highly configurable text editor with LSP support
- **Visual Studio Code** - IDE for modern development
- **PHP** - PHP runtime with Composer and development tools (PHPStan, PHP-CS-Fixer, Rector, PHPCS)
- **Python** - Python runtime with development tools (Black, Flake8, Mypy, Pre-commit)
- **Go** - Go programming language
- **Git** - Version control with custom configuration

### Applications
- **Firefox** - Web browser
- **Discord & Telegram** - Communication apps
- **Spotify** - Music streaming
- **Obsidian** - Note-taking and knowledge management
- **VLC** - Media player
- **Zathura** - PDF viewer
- **Thunar** - File manager
- **WireGuard** - VPN tools

### System Utilities
- **Arch-update** - System update notifier
- **Better Control** - Audio device control
- **Trash-cli** - Command-line trash management
- **GitHub CLI** - GitHub integration
- **Flatpak** - Universal package management

### Theming
- **Catppuccin Mocha** - Color scheme used across all applications
- **JetBrains Mono Nerd Font** - Primary font with icon support
- **Font Awesome** - Icon font for UI elements
