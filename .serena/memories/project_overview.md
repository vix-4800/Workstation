Workstation is an Arch Linux + Sway machine state management repository built around Ansible roles. Main entrypoints are site.yml and Justfile. Inventory lives under inventory/, secrets templates under vault/, and roles under roles/. The ai-tools role manages CLI AI tooling and dotfile symlinks. Project instructions emphasize minimal scoped changes, symlink-based config deployment, 2-space YAML indentation, role/type tags on tasks, bash scripts with set -euo pipefail, and never versioning secrets or machine-local runtime state.
