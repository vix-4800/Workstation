# Swappy Configuration

Swappy - инструмент для редактирования скриншотов в Wayland.

## Использование

### Горячие клавиши в Sway
- `Ctrl+Print` - Сделать скриншот области и открыть в Swappy для редактирования

### Из командной строки
```bash
# Редактировать существующий скриншот
swappy -f screenshot.png

# Захватить область и редактировать
grim -g "$(slurp)" - | swappy -f -
```

## Возможности
- Рисование линий, стрелок, прямоугольников
- Добавление текста
- Размытие областей
- Обрезка изображения
- Сохранение в ~/Pictures/Screenshots

## Конфигурация
Файл: `~/.config/swappy/config`

Основные настройки:
- `save_dir` - директория для сохранения (по умолчанию ~/Pictures/Screenshots)
- `line_size` - толщина линий (5)
- `text_size` - размер текста (20)
- `text_font` - шрифт (JetBrains Mono Nerd Font)
